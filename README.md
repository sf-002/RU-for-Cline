# Cline RU — русификатор интерфейса Cline

> ⚠️ **Вайбкод (vibe code).** Всё содержимое сделано «на вайбе»: наспех, скриптами, без тестов и без гарантий. Используйте на свой риск. Ничего не подефолту не гарантируется, код может не работать на других версиях Cline.

Набор скриптов и данных для русификации интерфейса расширения **Cline** (`saoudrizwan.claude-dev`) для VS Code: патчим строки в собранных бандлах расширения и подменяем их русскими.

## Что внутри

| Файл | Назначение |
|---|---|
| `scan_cline_strings.ps1`, `scan2.ps1` … `scan4.ps1` | Сканирование бандлов Cline и сбор англоязычных строк |
| `apply_ru.ps1`, `apply_ru2.ps1`, `apply_ru3.ps1` | Применение словаря переводов к бандлу расширения |
| `apply_pkg.ps1` | Патч `package.json` (заголовки команд/меню) |
| `cline_ru_dict.json` … `cline_ru_dict4.json` | Словари перевода (по итерациям) |
| `cline_pkg_dict.json` | Словарь строк для `package.json` |
| `patched.mjs` … `patched7.mjs` | Пропатченные (уже переведённые) бандлы |
| `*-out.txt`, `inv*.txt`, `cand*.txt`, `ctx_*.txt` | Артефакты сканирования и разведки бандлов |
| `apply_report*.txt`, `apply_pkg_report.txt` | Отчёты о применении патчей |

## Принцип работы

1. Бандлы Cline (`dist/extension.js` и webview-сборки) — это большой минифицированный JS.
2. Скрипты `scan*` находят в них англоязычные строки интерфейса.
3. Строки переводятся и складываются в словари `cline_ru_dict*.json` (пары «оригинал → перевод»).
4. Скрипты `apply_ru*` заменяют строки в бандле на русские и сохраняют результат.

## Как применить (кратко)

```powershell
# 1. Найти установленное расширение
$ext = "$env:USERPROFILE\.vscode\extensions\saoudrizwan.claude-dev-<version>"

# 2. Сделать бэкап
Copy-Item "$ext\dist\extension.js" "$ext\dist\extension.js.bak"

# 3. Применить словарь (скрипт правит extension.js)
powershell -ExecutionPolicy Bypass -File .\apply_ru3.ps1

# 4. Перезагрузить VS Code
```

> Версия, под которую делалась русификация, — **4.1.20**. Для других версий часть строк не совпадёт: словарь придётся дополнять (`scan*` → перевод → `apply_ru*`).

## Дополнительно

Скрипты `ctx_*.ps1` и `inv*.ps1` — вспомогательные: собирали контекст по UI, правилам, табам, автоподтверждению и MCP, чтобы понимать, что переводить.

Русские строки для самого агента (не UI) лежат отдельно — см. правило `russian-language.md`.
